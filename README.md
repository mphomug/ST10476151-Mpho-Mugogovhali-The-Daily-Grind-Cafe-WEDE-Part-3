CSS Styling and Responsive Design:
The Daily Grind Café website was styled using an external CSS stylesheet. The
stylesheet was linked to all five HTML pages to maintain a consistent design throughout the website.
The website uses a warm café colour scheme with brown, cream and white colours. Typography was adjusted using different font sizes, font weights, line spacing and letter spacing to create a clear visual hierarchy.
 
Flexbox was used to arrange the header, café logo, website name and navigation links. Sections, buttons, forms and other content were also styled using padding, margins, borders, rounded corners and box shadows.
Responsive design was added using CSS media queries. The website was tested at
desktop, tablet and mobile screen sizes. The navigation, text, buttons, forms and other content adjust to fit smaller screens.
Relative units such as percentages, rem and em were used to help the website adapt to different screen sizes. Responsive image attributes using srcset and sizes were also
added.

JavaScript Functionality and Interactive Features:
JavaScript was used to improve the functionality and interactivity of The Daily Grind Café website. A loading screen featuring the café logo was added to create a short, animated transition when visitors open the website.
The menu page includes a search function that allows customers to search for specific coffee and food items. Expandable menu sections were also added to display additional information about each product. A shopping cart was implemented to allow customers to add items, adjust quantities, remove products and view the total cost of their order. The checkout function prepares an email containing the customer's order details.
JavaScript validation was added to both the enquiry and contact forms to check that customers enter the required information correctly. After successful validation, the website prepares an email containing the submitted information.

Search Engine Optimisation (SEO):
Search Engine Optimisation (SEO) improvements were made to help search engines understand the content of The Daily Grind Café website. Unique page titles, meta descriptions and keywords were added to all five HTML pages. Headings were organised to make the website content easier to understand, while alternative text was added to images to improve accessibility.
A sitemap.xml file was created to list the website pages, and a robots.txt file was added to provide instructions to search engine crawlers. The website also includes relevant café information, such as its location in Melville, Johannesburg, contact details and opening hours, to support local search visibility.
